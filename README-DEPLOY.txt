NOMAD RIDE CO. — CINEMATIC WEBSITE DEMO

This folder contains the static motorcycle-rental website concept for local testing or static hosting.

The demo uses illustrative branding, photography, vehicle categories and copy. The enquiry form creates a local preview only; it has no real recipient, does not send data, and is not a booking or payment backend.

Before adapting for a client:
- Replace demo branding with the client's approved identity.
- Replace sample photos and categories with the client's actual fleet and approved media.
- Add the real address, operating hours, contact channels, current pricing and rental policies only after confirmation.
- Replace illustrative story content with real customer material only with permission.
- Add a booking/enquiry integration only once an authorized destination and privacy disclosures are supplied.
- Review the current Pexels licensing and usage requirements before any commercial launch.

Open index.html through a local server during testing. The videos are locally stored and load lazily for performance.
